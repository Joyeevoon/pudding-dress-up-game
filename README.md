# 布丁酱的换装小屋 ❤️

一个可爱的二次元换装小游戏！为布丁酱搭配10套精美的洛丽塔服装。

![游戏预览](uploads/f2eaee50-b3c3-45c6-82ca-ac7be91d888b.webp)

## ✨ 功能特性

- 👗 **10套精美服装**：奶油草莓、春日来信、暖橘元气、暗黑童话、森林来信、海盐布丁、紫罗兰的夜晚、蓝色水母、雾雨深林、青涩柠檬
- 🎵 **背景音乐**：可爱的背景音乐，支持播放/暂停控制
- 📱 **全端适配**：手机竖屏和电脑端都完美适配（电脑端保持手机比例居中显示）
- 🎀 **二次元可爱UI**：粉色系可爱风格设计
- ⚡ **流畅体验**：所有图片预加载，换装无延迟

## 🎮 玩法

1. 进入游戏，点击屏幕任意位置启动背景音乐
2. 点击右侧服饰按钮，布丁酱立即换装
3. 使用右上角音乐按钮（标题旁边）控制音乐播放/暂停

## 🚀 本地运行

这是一个纯静态HTML项目，无需构建：

```bash
# 方法1：直接打开
双击 index.html 即可在浏览器中打开

# 方法2：使用本地服务器（推荐）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## ☁️ 部署到 GitHub Pages

1. 把这个仓库推送到 GitHub
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，目录选 `/ (root)`
4. 保存后等待几分钟，即可通过 `https://你的用户名.github.io/仓库名/` 访问
